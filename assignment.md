# 🚀 DevOps AI Agent – Feature Extension Assignment

## 📌 Assignment Overview

In this assignment, you will extend the existing **DevOps AI Agent** by adding a new DevOps capability.

The current DevOps AI Agent includes features such as:

- Kubernetes status analysis
- Incident investigation
- Root cause analysis
- Deployment reviews
- Infrastructure as Code (IaC) reviews

Your task is to add **one new feature** to the existing project.

You are free to design and implement the feature in your own way.

---

# 🎯 Objective

Your feature should:

1. Solve a DevOps-related problem.
2. Accept relevant input.
3. Analyze the input.
4. Return meaningful findings or results.
5. Provide recommendations where applicable.
6. Integrate with the existing DevOps AI Agent project.

Try to follow the existing application architecture where appropriate.
